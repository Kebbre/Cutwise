# Cutwise

Cutwise is a practical planning tool designed to help optimise wood cutting layouts for DIYers, makers, and professionals.

The app allows you to create **plank** and **sheet** projects, generate optimised cut plans, visualise off-cuts clearly, and reduce material waste before cutting or buying materials.

Cutwise is intended as a **planning aid** to support better decision-making and more efficient use of wood.

---

## Features

- Plank projects for linear elements (boards, battens, strips)
- Sheet projects for panels and boards
- Optimised cut layouts accounting for kerf width
- Clear visualisation of cuts and off-cuts
- Save and load projects
- Export full cut plans as multi-page PDF documents
